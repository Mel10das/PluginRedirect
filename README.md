# Plugin Redirect Fixer

WordPress плагин для автоматического обнаружения и замены ссылок с 301 редиректом на конечные URL.

## Описание

Plugin Redirect Fixer сканирует ваш WordPress сайт и находит все ссылки, которые ведут на 301 редирект. Затем плагин заменяет эти ссылки на конечные URL, что улучшает производительность сайта и SEO.

### Основные возможности

- Автоматическое сканирование всех постов и страниц
- Обнаружение цепочек редиректов (301, 302, 303, 307, 308)
- Замена ссылок с редиректами на конечные URL одним кликом
- Проверка отдельных URL на наличие редиректов
- Удобный интерфейс в админ-панели WordPress
- Показывает полную цепочку редиректов для каждой ссылки

### Зачем это нужно?

1. **Улучшение SEO** - поисковые системы предпочитают прямые ссылки
2. **Ускорение загрузки** - редиректы замедляют загрузку страниц
3. **Улучшение UX** - пользователи быстрее попадают на нужную страницу
4. **Избежание битых ссылок** - если промежуточная страница удалена, ссылка перестанет работать

## Установка

### Автоматическая установка

1. Войдите в панель администратора WordPress
2. Перейдите в "Плагины" → "Добавить новый"
3. Найдите "Plugin Redirect Fixer"
4. Нажмите "Установить" и затем "Активировать"

### Ручная установка

1. Скачайте архив плагина
2. Загрузите папку `plugin-redirect-fixer` в директорию `/wp-content/plugins/`
3. Активируйте плагин через меню "Плагины" в WordPress

### Установка через Git

```bash
cd wp-content/plugins/
git clone https://github.com/Mel10das/PluginRedirect.git plugin-redirect-fixer
```

Затем активируйте плагин в админ-панели WordPress.

## Использование

### Сканирование сайта

1. Перейдите в **Инструменты → Redirect Fixer**
2. Во вкладке "Сканер контента" нажмите кнопку **"Начать сканирование"**
3. Плагин просканирует все опубликованные посты и страницы
4. Результаты покажут список постов с найденными редиректами

### Исправление редиректов

1. После сканирования вы увидите список постов с редиректами
2. Для каждого поста будет показана информация о найденных редиректах:
   - Оригинальный URL
   - Конечный URL
   - Количество редиректов в цепочке
3. Нажмите кнопку **"Исправить редиректы"** для автоматической замены
4. Плагин заменит все ссылки в посте на конечные URL

### Проверка отдельного URL

1. Перейдите во вкладку **"Проверка URL"**
2. Введите URL в поле ввода
3. Нажмите **"Проверить"**
4. Плагин покажет:
   - Есть ли редирект
   - Конечный URL
   - Полную цепочку редиректов (если есть)

## Технические детали

### Требования

- WordPress 5.0 или выше
- PHP 7.0 или выше
- Включенная функция `wp_remote_head()` (по умолчанию включена в WordPress)

### Как это работает

1. **Сканирование**: Плагин использует регулярные выражения для поиска всех ссылок в контенте постов
2. **Проверка редиректов**: Для каждой ссылки отправляется HEAD-запрос с отключенным автоматическим следованием за редиректами
3. **Анализ цепочки**: Плагин следует по цепочке редиректов до конечного URL (максимум 5 редиректов)
4. **Замена**: Найденные ссылки заменяются на конечные URL в контенте поста

### Поддерживаемые коды редиректов

- 301 (Moved Permanently)
- 302 (Found / Moved Temporarily)
- 303 (See Other)
- 307 (Temporary Redirect)
- 308 (Permanent Redirect)

### Безопасность

- Проверка прав доступа (только администраторы)
- AJAX nonce для защиты от CSRF
- Валидация и экранирование всех входных данных
- Отключена прямая загрузка файла плагина

## API и Хуки

Плагин предоставляет следующие методы для разработчиков:

```php
// Получить экземпляр плагина
$plugin = Plugin_Redirect_Fixer::get_instance();

// Проверить URL на редиректы
$result = $plugin->check_redirect('https://example.com');

// Сканировать контент на наличие ссылок с редиректами
$redirects = $plugin->scan_content_for_redirects($content);

// Исправить редиректы в контенте
$fixed_content = $plugin->fix_redirects_in_content($content, $redirects);
```

## Часто задаваемые вопросы

### Как часто нужно запускать сканирование?

Рекомендуется запускать сканирование:
- После добавления большого количества нового контента
- Периодически (раз в месяц/квартал)
- При подозрении на битые или устаревшие ссылки

### Изменяет ли плагин оригинальный контент?

Да, плагин обновляет контент постов, заменяя ссылки. Рекомендуется создать резервную копию перед массовым исправлением.

### Работает ли плагин с пользовательскими типами постов?

В текущей версии плагин работает только с постами (post) и страницами (page). Поддержка пользовательских типов постов будет добавлена в будущих версиях.

### Влияет ли плагин на производительность сайта?

Плагин работает только в админ-панели и не влияет на производительность фронтенда. Сканирование выполняется по запросу и может занять время для больших сайтов.

### Что делать, если плагин находит ложные редиректы?

Вы можете проверить каждый URL отдельно во вкладке "Проверка URL" перед тем, как применять автоматическое исправление.
